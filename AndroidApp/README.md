# Mobile Tracker Free - Android App

This is a native Android app developed in Kotlin that implements core tracking features such as GPS location tracking, call monitoring, and SMS monitoring. The app is structured to allow future integration with a backend service for data synchronization.

## Features Implemented
- GPS location tracking with periodic updates
- Call state monitoring (incoming, outgoing, missed calls)
- SMS sent and received monitoring
- Basic UI to display tracking status and collected data
- Permissions handling for location, phone, and SMS

## Future Work
- Integration with backend APIs for real-time monitoring and data upload
- Additional features such as social network tracking and remote control
- Enhanced UI/UX and security features

## Setup
- Developed with Kotlin and Android SDK
- Minimum SDK version: 21 (Android 5.0 Lollipop)
- Target SDK version: 33 (Android 13)
- Requires runtime permissions for location, phone, and SMS

## How to Build
- Open the project in Android Studio
- Sync Gradle and build the app
- Run on a physical device or emulator with required permissions granted

## Disclaimer
This app is intended for legal use only, such as monitoring children with their consent. Ensure compliance with local laws and regulations before using tracking features.
